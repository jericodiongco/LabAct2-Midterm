ABOUT THIS BUILD

How It's Built

COURTSIDE is a Bootstrap-powered showcase gallery for CCS114, built with plain HTML, CSS, and Bootstrap components only — no custom JavaScript. Every layout decision below maps to a specific Bootstrap feature.

6
Sport categories
5+
Column configurations
2
Interactive features

The header uses navbar-expand-lg with a collapsible menu, so it folds into a hamburger toggle below the large breakpoint.

The hero uses col-lg-7 / col-lg-5, stats use col-6 col-md-3, the gallery uses col-12 col-sm-6 col-lg-4 col-xl-3, this section uses col-lg-6, and the contact form uses a centered col-lg-8 — five distinct configurations.

Cards get a hover lift with a caption overlay (pure CSS), and every card opens a Bootstrap Modal with the full image, title, and description — both work with zero custom JavaScript.

Navbar, Carousel, Grid, Cards, Modal, Badges, Nav Pills/Tabs, Accordion, and Form controls — all driven by Bootstrap's own data attributes.
